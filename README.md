# mini X URL Extension

ミニXの投稿に含まれるURLをリンクに変換し、本文の下にタイトル・サムネイル付きのプレビューカードを表示するChrome拡張機能です。

## このプロジェクトについて

[jig.jp](https://jig.jp/)主催の11月の開発お題「ミニXの拡張機能を作ってみよう！」をきっかけに作成したプロジェクトです。

対象は、勉強会「[ミニX をつくろう](https://github.com/jigintern/study_session_materials/tree/main/2026/mini-x)」の教材をもとに構築したミニXです。

## できること

- 投稿本文に含まれるHTTP・HTTPSのURLをリンク化。複数のURLにも対応します。
- 本文の下に、ドメイン・ページタイトル・サムネイルをまとめたカードを表示します。
- 本文のリンクとカードは、クリックすると別タブで開きます。

## 利用に必要なもの

- Google Chrome
- `http://localhost:8000/` で動作するミニX

ミニXのサーバー本体は、教材をもとに別途用意してください。

## インストール方法

1. このリポジトリをダウンロード、またはクローンします。ZIPでダウンロードした場合は展開してください。
2. Chromeのアドレスバーに `chrome://extensions/` を入力して、拡張機能の管理ページを開きます。
3. 右上の「デベロッパー モード」をオンにします。
4. 「パッケージ化されていない拡張機能を読み込む」をクリックします。
5. このリポジトリ内の **`extension` フォルダー**を選択します。
6. ミニXを開きます。すでに開いている場合は再読み込みしてください。

## 使い方

拡張機能を有効にした状態で、URLを含む投稿を表示すると、自動でリンクとプレビューカードが追加されます。

## 注意事項

- プレビューの取得はHTTPSのURLが対象です。HTTPのURLはリンク化のみ行います。
- サイトによっては、タイトルや画像を表示できない場合があります。
- URLの直後に文章を続ける場合は、空白や改行で区切ってください。
